# iDEZ SPORT — Сайт-лендинг нейтрализатора запаха

## Стек
- React + Vite
- Framer Motion (анимации)
- Three.js + @react-three/fiber (3D флакон)
- CSS Variables (без Tailwind)

## Шрифты
- Заголовки: 'Barlow Condensed', weight 900, UPPERCASE
- Текст: 'Barlow', weight 300-400
- Подключить через Google Fonts в index.html

## Дизайн-правила
- Фон всегда тёмный (#0a0a0a или #111)
- Изумруд ТОЛЬКО для акцентов: кнопки, цифры, иконки, первое слово
- Флакон (фото/3D) — единственный белый элемент
- Разделители между блоками: 1px solid #2a2a2a
- Кнопки: без border-radius (острые углы) ИЛИ border-radius 2px max
- Шрифт всегда UPPERCASE для заголовков и навигации

## О продукте
Натуральный дезодорант-антисептик для обуви.
Состав: масло чайного дерева (убивает грибки/бактерии),
масло пихты (нейтрализует запах, подсушивает кожу),
масло эвкалипта (освежает, помогает проникновению).
Без химии, алюминия, парабенов. Безопасно для детей.
Применение: спрей внутрь обуви вечером после носки.
Эффект накопительный — чем дольше используешь, тем лучше.
